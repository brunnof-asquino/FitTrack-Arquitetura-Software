# Glossário inicial do FitTrack

| Termo | Significado no contexto do FitTrack |
|---|---|
| Usuário | Pessoa cadastrada que pode manter perfil e interagir com treinos. |
| Treino | Publicação criada por um usuário, com título, descrição e vídeo/capa associados. |
| Curtida | Registro de interação de um usuário com um treino. |
| Comentário | Texto publicado por um usuário em relação a um treino. |
| Feed | Listagem de treinos para descoberta e consulta de conteúdo. |
| Perfil público | Informações de perfil disponibilizadas para consulta por outros usuários. |
| Caso de uso | Operação da aplicação que realiza uma intenção, como publicar treino ou comentar. |
| Repositório | Contrato de acesso a objetos/dados do domínio, separado da implementação de persistência. |
| Adaptador | Componente que conecta a arquitetura a uma tecnologia externa, como HTTP, banco de dados ou armazenamento de mídia. |
| Contexto delimitado | Limite dentro do qual um modelo de domínio e seus termos têm significado consistente. |

Este glossário é inicial e deve ser ajustado conforme os requisitos e o vocabulário usado efetivamente pelo projeto.
